# Data

The competition data is **not included** (Kaggle competition rules generally forbid redistribution).

1. Join the competition: **Engage 2 - Value from Clicks to Conversions** (`engage-2-value-from-clicks-to-conversions`).
2. Download the files into `data/raw/`:
   ```bash
   kaggle competitions download -c engage-2-value-from-clicks-to-conversions -p data/raw
   unzip data/raw/*.zip -d data/raw
   ```
3. You should end up with `data/raw/train_data.csv` and `data/raw/test_data.csv`.
